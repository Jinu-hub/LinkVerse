この1年、私は新しいことを学び、作り、止まり、また始め直すことを繰り返してきた。

実際にデプロイしたサービスもいくつかある。いまは保留になっているものもあれば、まだ可能性を確かめている段階のものもある。

AIを活用した開発の仕方もかなり変わり、サービスを自分で運用するなかで、開発だけでは解決できない問題にも出会った。

だから、いまの時点でこの1年の自分を一度振り返ってみたかった。

何を学んだのか。何を作ったのか。どこで行き詰まったのか。

そしていま何をしていて、次はどこへ向かおうとしているのか。

大きな振り返りというより、いまの考えを整理する意味で、10の質問を作って自分で答えてみることにした。

## 1. この1年、どんな勉強をしましたか？

チャレンジへの参加だけでいえば、1年前に参加したメーカーマスタークラスに続き、今回の Open Claw が2回目だ。

それでも、そのあいだも新しい技術は続けて学んできた。

AI Agent を組み立て、複数のツールやデータをつなぐ方法、  
n8n を使って多段階の作業を自動化するパイプライン設計、MCP を使って AI と外部機能をつなぐ方法などを身につけた。

最近は Cloudflare Workers をベースに、State や Storage、リアルタイム通信などを使った Agent の構造も自分で作ってみている。

振り返ると、ひとつの技術を深く掘ったというより、AI を中心に開発の仕方がどう変わっているかを追いかけ続けた時間に近かった気がする。

そのあとに作ったプロジェクトも、その都度学んだことの影響をかなり受けている。

## 2. これまでどんなサービスを作ってみましたか？

この1年でデプロイまでしたサービスは、だいたい3つだ。

チャレンジで作った最初のサービス `LinkVerse` は、その後いったん保留にした。
サービスは公開されているので、たまに訪れる人はいるが、
実際にちゃんと使っているのはおそらく自分だけだろう。

次に作ったのが `NexLetter` というサービスだ。

複数の Slack チャンネルの会話を集め、AI が全体を要約して週次レポートを作り、メールで送るサービスだった。

サービス自体はある程度できたが、Slack App の審査が想定より長引き、そのまま流れが途切れて、いまは保留状態だ。

その次が、いまも運用している `Market Memory` だ。

グローバル市場関連のソースを集めると、AI Agent と複数の n8n ノードが協力してデータを加工し、レポートを作る。  
生成された結果はデータベースに保存し、ウェブで見せる。

このサービスは実際にローンチし、いまもデータを積み続けている。

ただ、ひとつ大きな問題がある。

**人がほとんど来ない。**

Threads などでたまに知らせてはいるが、まだ手応えを感じられるほどのトラフィックは得られていない。

## 3. ブログはなぜ書き続けているのですか？

ブログには、だいたい週に1回くらい文章を残している。

専門的な技術ブログというより、いま作っていること、開発しながら下した判断、個人的な考えや計画、ときどき日常の記録を残す場所に近い。

いま誰かに見せるためというより、あとから自分で読み返すための目的もかなり大きい。

時間が経って昔の文章を読むと、当時何に悩み、なぜその選択をしたのかが残っている。

結果だけを見ると見えないものが、記録には残る。

だから、完成した結果と同じくらい、その過程も書き続けようとしている。

## 4. 1人開発をしていて、いちばん難しかったことは何ですか？

開発そのものには、それなりに自信があると思ってきた。

問題が起きれば解決の道を探せるし、時間がかかっても、結局は望む形まで作れると思っている。

ところが、サービスを作ってみると、まったく別の問題が待っていた。

**製品を作ることと、製品を広めることは、まったく別の能力だった。**

Market Memory を作っていたころは、Phase 1 で基本的なサービスを仕上げ、ある程度流入が生まれたら、  
ユーザーのフィードバックを受けながら Phase 2 を作っていくつもりだった。

だが、その予想はかなり外れた。

Phase 2 を考える前に、まず人を集めること自体が難しかった。

自分から見てそれなりのコンテンツができていることと、人々がそれを必要としていることは、同じ話ではなかった。

いま、最も強く実感しながら学んでいることだ。

開発さえうまくいけばいいとは思っていなかったが、両者のあいだの隔たりがここまで大きいことは、実際にサービスを運用してから実感した。

## 5. それでもうまくやれたと思う部分は何ですか？

Market Memory で技術的にいちばん満足している部分のひとつは、n8n パイプラインだ。

ひとつの巨大な Workflow がすべてを処理するようにはしなかった。

元データを受け取り Core Data を作る流れがあり、そのデータを基にタグや企業・人物・技術といった Entity データを作る流れがある。

レポートも、種類に応じて別々のパイプラインを通って生成される。

そしてそれぞれの過程のなかで、複数の Sub Workflow が役割を分けて処理する。

最初に設計したときより構造はかなり大きくなったが、  
それぞれのパイプラインが独立して動きながら、ひとつの結果を生み出すようにした経験は、これから別のプロジェクトでも多く使えそうだ。

反対に、物足りない部分もはっきりしている。

**自分が良いコンテンツだと思うものと、人々が本当に求めているものは、違うことがある。**

技術的な完成度を上げるだけでは、この問題は解決できない。

この部分は、まだ答えを探している。

## 6. AI によって、開発の仕方はどれくらい変わりましたか？

1年前は、AI と自分がコードを書く割合が、感覚としてはだいたい 5:5 くらいだった気がする。

AI がコードを書くと、かなり丁寧に確認し、自分で直す部分も多かった。

いまはほぼ 9:1 に近づいている。

コードを一つ一つ確認することも、かなり減った。

実装のほとんどは AI に任せ、必要なときに構造を確認したり、リファクタリングを頼んだりする。  
大事なところで方向が合っているかを見たり、おかしな流れが生まれていないかを確認するほうに、より多くの時間を使う。

自分の役割が、実装そのものから少しずつ離れているということでもある。

代わりに、何を作るか、どんな構造にするか、AI が作った結果をどこまで信頼するかという判断は、より重要になっている。

今回の Open Claw では、その変化がまた別の形で感じられる。

単に AI でコードを速く作ることを超えて、Agent そのものをどう組み立て、どう運用するかを扱っているからだ。

## 7. Open Claw でいちばんおもしろかったことは何ですか？

Cloudflare Workers をベースに、Agent が必要なときに必要なだけ動き、また消えるという構造が、個人的にはかなり興味深かった。

ここに State、Storage、WebSocket、Scheduling のような機能をつなぐと、小さな Agent ひとつでも思ったより多くのことができる。

特に関心があるのはパーソナライズだ。

すべてのユーザーに同じ画面と同じ情報を見せるのではなく、  
それぞれの関心や状態を覚え、それに応じて異なる情報を見せる仕組みを作るのに向いているという気がした。

そしてこの部分が、いま Market Memory で行き詰まっている点とつながるかもしれない、と考え始めている。

## 8. いまいちばん作ってみたいものは何ですか？

まったく新しいサービスをもうひとつ作るというより、いまは Open Claw で学んでいることを Market Memory につないでみたい。

Market Memory には、すでにいろいろな種類のコンテンツとデータがある。

そのなかでもいちばん基本的でフォーマルな `Daily Global Market Issues` から、新しい表現を試してみるつもりだ。

たとえば、その日の市場をごく短くまとめた **今日の30秒ブリーフィング** を、テキストとオーディオで提供できる。

これまで蓄積したタグや Entity データを使い、どの企業や技術、テーマが最近よく登場しているかも見せられる。

ユーザーが関心を持つ市場やテーマを覚え、次の訪問で関連する内容を少し優先して見せることもできるだろう。

もう少し実験的なアイデアとしては、`Live Market Room` も考えている。

特定の時間だけ一時的に開かれる場をつくり、そのなかで今日のブリーフィングを見たり、簡単な投票や意見のやりとりができるようにする、といった形だ。

いまはまだ、いくつかの可能性を試している段階だ。

だが少なくとも、既存のデータをただ画面に並べるより、ユーザーの状況に合わせて見せ直す方向は、続けて試してみたい。

## 9. ひとつを続けるか、新しいものを作るかで悩みますか？

かなり悩む。

これまで3つのサービスをデプロイし、うち2つはいま保留状態だ。

Market Memory だけに取り組み続けるのが正しいのか、それともまったく新しいアイデアを開発したほうがいいのか、考えることもある。

ただ、保留にしたプロジェクトを、失敗して捨てたものだとは思っていない。

NexLetter を作りながら身につけた構造と自動化の経験は、Market Memory の開発にもつながった。

Market Memory で経験したデータ構造や Agent の使い方も、いまの Open Claw を見る目に影響を与えている。

あとで、まったく別のプロジェクトでまたつながるかもしれない。

だから最近は、少し違うふうに考えている。

**いまは、点を打ち続けていく過程だ、と。**

どの点がどこでつながるかは、まだわからない。

だが、何も作っていなければ、つながる点そのものが存在しなかったはずだ。

## 10. これからも1人開発を続けますか？

たぶん、続けると思う。

新しい技術も、続けて学ぶつもりだ。

とくに変化の速いいまは、新しい講座を受けたり、プロジェクトに取り組んだりするだけでも、自分が当たり前だと思っていた開発の仕方を、あらためて見つめ直すことが多い。

Market Memory は、短期的な成果だけを見て終わりにするより、もう少し長く続けてみたい。

いまは流入という大きな課題が残っていて、方向を変える必要がある部分もきっとある。

そのなかで新しいアイデアが生まれたら、またひとつ作ることもあるだろう。

この1年も、そうやって動いてきた。

学び、作り、デプロイし、止まり、また別のものを作った。

そのなかのどれが、結局結果につながるのかは、まだわからない。

ただ、ひとつだけは、以前より少しはっきりしてきた。

成功した点だけを残さなければならないわけではない。

保留にしたプロジェクトにも経験は残り、期待どおりに進まなかったサービスからも学ぶことがあった。

そしてその経験は、少しずつ次の作業へとつながっている。

まだ何かを完成させたと言うより、

**私はいまも、点を打ち続けている。**

いまは互いに遠く離れて見える点でも、いつか振り返ったとき、ひとつの流れとしてつながっているかもしれない。

いまは、そのくらいの考えで作り続けていこうと思っている。
